Report Formatting Utilities

01 — Cleanup

Border Cleanup

applyHideBorderForEmptyCellsByHeader(headerNames) — strips styling from cells that are genuinely empty, in the columns you name.

// Dynamic Action → Execute JavaScript Code
applyHideBorderForEmptyCellsByHeader(["Remarks", "Notes"]);
02 — Single Report

Total Rows (Single Report)

applyReportTotalFormatting() — no arguments, formats every "...TOTAL:" row it finds.

// Dynamic Action → Execute JavaScript Code (single-report page)
applyReportTotalFormatting();
03 — Multi-Report

Total Rows (BGW)

applyReportTotalFormattingAllBGW(addSpacer) — same formatting, looped across every report table on the page.

// Dynamic Action → Execute JavaScript Code (Break-Group-With page)
applyReportTotalFormattingAllBGW();      // no spacer rows
applyReportTotalFormattingAllBGW("Y");   // adds spacer row after each group's last total
04 — Fine Control

Total Row Column Control

handleReportTotal(reportStaticId, options) — jQuery-based control over one specific total row.

Call Syntax
All four actionType/fullRow combinations, from the docblock examples.
// Hide the entire "Report Total:" row
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  fullRow: true
});

// Hide just the PP #, Amount, and Qty columns in that row
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  headers: ["PP #", "Amount", "Qty"],
  actionType: "hide"
});

// Blank out (empty) the PP # and Amount columns
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  headers: ["PP #", "Amount"],
  actionType: "null"
});

// Remove the PP # column cell entirely
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  headers: ["PP #"],
  actionType: "remove"
});
Recap

All Four, Called Together

Now that you've seen what each one does — a realistic Dynamic Action combining cleanup, single-report totals, BGW totals, and column-level control.

// Dynamic Action → Execute JavaScript Code (After Refresh, on the report region)

// 1) Clean up empty Remarks/Notes cells — no border/background on blanks
applyHideBorderForEmptyCellsByHeader(["Remarks", "Notes"]);

// 2a) Single-report page — format every "...Total:" row
applyReportTotalFormatting();

// 2b) Break-Group-With page — same formatting, once per group, with spacer rows
applyReportTotalFormattingAllBGW("Y");

// 3) Hide the entire "Report Total:" row on a specific region
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  fullRow: true
});

// 4) Or blank out just the PP # and Amount columns instead of hiding the row
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  headers: ["PP #", "Amount"],
  actionType: "null"
});
