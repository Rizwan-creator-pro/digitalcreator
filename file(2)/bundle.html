Product 2

Report Formatting Utilities

Four functions for classic reports — border cleanup, TOTAL rows, BGW support, and column control. Full guide →

1
Drop the functions in
Paste the script into a page-level JavaScript function, or a static application file loaded on every page. All four functions ship in one file.
2
Pick single-report or BGW
applyReportTotalFormatting() for a page with one report; applyReportTotalFormattingAllBGW() for Break-Group-With pages with several.
3
Run it after render
Wire it to a Dynamic Action → Execute JavaScript Code, on Page Load or After Refresh on the report region.
// Dynamic Action → Execute JavaScript Code
applyHideBorderForEmptyCellsByHeader(["Remarks", "Notes"]);
applyReportTotalFormatting();
All Four, Called Together
A realistic Dynamic Action combining cleanup, single-report totals, BGW totals, and column-level control.
// Dynamic Action → Execute JavaScript Code (After Refresh, on the report region)

// 1) Clean up empty Remarks/Notes cells — no border/background on blanks
applyHideBorderForEmptyCellsByHeader(["Remarks", "Notes"]);

// 2a) Single-report page — format every "...Total:" row
applyReportTotalFormatting();

// 2b) Break-Group-With page — same formatting, once per group, with spacer rows
applyReportTotalFormattingAllBGW("Y");

// 3) Hide the entire "Report Total:" row on a specific region
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  fullRow: true
});

// 4) Or blank out just the PP # and Amount columns instead of hiding the row
handleReportTotal("JKP", {
  totalRowName: "Report Total:",
  headers: ["PP #", "Amount"],
  actionType: "null"
});
